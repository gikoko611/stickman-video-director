# G.I KO KO — F-35 Lightning II 3D Explainer

Five-minute procedural 3D educational animation rendered with Blender Workbench and assembled with FFmpeg. Burmese narration uses the Microsoft Neural voice IDs my-MM-ThihaNeural / my-MM-NilarNeural. Burmese subtitles are delivered as a separate SRT file to avoid garbled glyphs in the video.

## Run
1. Open GitHub Actions.
2. Select **F-35 Lightning II 3D Explainer**.
3. Choose standard or compact and press **Run workflow**.
4. Download the artifact **GI-KO-KO-F35-Lightning-II-3D-Explainer**.

No Deepgram key is required. Edge TTS needs internet access during the workflow run.

## Visuals
Cinematic 3D aircraft exterior orbit, animated exploded view of major external assemblies, cockpit, landing gear, and a simplified engine demonstration. Includes Burmese narration, separate subtitles, original ambient score, and synthesized jet-style sound design.

## Accuracy and safety
This is an educational visualization, not factory CAD, a manufacturing blueprint, or an exact engineering replica. It excludes classified low-observable shaping details, internal weapon integration, sensor algorithms, and actionable military construction procedures. The simplified engine insert is conceptual only. Aircraft facts are based on public official fact sheets.

## Output
5:00 target runtime; 1280×720 at 12 fps; H.264 MP4 with AAC audio; separate Burmese SRT; narration text and production report.
