# G.I KO KO — F-35C Lightning II 3D Explainer

Five-minute F-35C carrier-variant educational animation rendered with Blender Eevee PBR and assembled with FFmpeg. The hybrid visual combines a cinematic aircraft hero model, carrier-specific exterior features, an animated exploded view. English narration is generated with Deepgram Aura-2 (aura-2-thalia-en). Myanmar Burmese subtitles are delivered as a separate SRT file, synchronized to the five-minute narration, to avoid garbled glyphs in the video.

## Run
1. Open GitHub Actions.
2. Select **F-35C Lightning II Hybrid 3D Explainer**.
3. Choose **high** for the default high-quality render, or standard / compact for faster alternatives, then press **Run workflow**.
4. Download the artifact **GI-KO-KO-F35C-Lightning-II-3D-Explainer**.

A Deepgram API key is required. In the GitHub repository, open Settings → Secrets and variables → Actions → New repository secret. Set the name to DEEPGRAM_API_KEY and paste your Deepgram API key as the value. Keep the key private; never put it in source code. The GitHub Actions workflow passes this secret to the render step.

## Visuals
F-35C public-reference exterior model with enlarged folding wings, reinforced carrier landing gear, twin nose wheels, arresting tailhook, cockpit, simplified engine demonstration, detailed panel seams, PBR materials, cinematic deck lighting, camera orbit and animated exploded view. High profile uses Eevee PBR at 128 samples, 1280x720, 12 fps, and AgX color management. Includes Deepgram English narration, synchronized Myanmar Burmese subtitles, original ambient score, and synthesized jet-style sound design.

## Accuracy and safety
This is a public-reference educational visualization, not factory CAD, a manufacturing blueprint, or an exact engineering replica. External proportions and carrier features are illustrative and should not be used as engineering dimensions. It excludes classified low-observable shaping details, internal weapon integration, sensor algorithms, and actionable military construction procedures. The simplified engine insert is conceptual only. Aircraft facts are based on public official fact sheets.

## Output
5:00 target runtime; 1280×720 at 12 fps; H.264 MP4 with AAC audio; separate Myanmar Burmese SRT; English narration script and production report.
